# NexusBTA v0.2.47

## MiniMax Music 3

- Adds a dedicated Music 3 template that stays isolated from image and video workflows.
- Selects the compatible local DiT, text encoder and DAV audio VAE from the configured models path.
- Supports RTX 3060 INT8 with tiled audio decoding and RTX 5090 FP16 with the faster non-tiled route.
- Adds three prompt modes: pure instrumental (`[instrumental]`), instrumental with wordless vocal textures, and vocal lyrics with caption. Caption-only generation can also receive optional negative guidance.
- Keeps mode, caption, lyrics, negative guidance, duration, Top K, CFG, format, quality and tiled decoding synchronized across the side menu, workflow preview and backend payload.
- Fixes `SaveAudioAdvanced` DynamicCombo serialization so Music 3 files are actually written after sampling completes.
- Adds audio output recovery and playback in Linear View, Gallery and the React frontend for MP3, FLAC, Opus, WAV, OGG and M4A files.

## MiniMax H3

- Keeps the isolated H3 T2V, I2V, REF2VA, first/last frame, nine-reference and booster routes synchronized with the side menu.
- Preserves H3 model-folder resolution and runtime paths without changing existing SD, Flux, Qwen, WAN, LTX or Anima workflows.

## Train LoRA

- Includes the corrected trainer/dependency configuration and Windows-safe UTF-8 logging fixes.
