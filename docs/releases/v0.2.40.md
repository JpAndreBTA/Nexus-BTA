# NexusBTA v0.2.40

## Gallery Workflow Isolation

- Sending a gallery item to txt2img transfers only its positive and negative prompts.
- Sending to img2img, inpaint or img2video transfers only prompts and the selected reference media.
- VAE, text encoders, video/audio VAE, latent upscale and Omnicine settings are no longer restored from gallery metadata.
- Concept, Lightning and distilled LoRAs remain unchanged in the active template.

## Validation

- Frontend tests used gallery items containing intentionally incompatible metadata.
- txt2img, img2img and img2video retained all current template assets and LoRAs.
- Positive/negative prompts and image/video references continued to transfer correctly.
- Inline JavaScript syntax and scoped diff validation passed.
