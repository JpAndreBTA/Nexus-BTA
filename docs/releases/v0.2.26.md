# NexusBTA v0.2.26

## Ideogram-4

- Added a dedicated Ideogram-4 template to the legacy `/ui` preset bar beside Anima.
- Added dependency and asset handling for Ideogram-4 fp8 model, unconditional fp8 model, Qwen3-VL text encoder and Flux2 VAE.
- Added optional dependency flow so users can choose what to download without forcing new installs.
- Preserved custom ComfyUI and custom_nodes paths and avoids duplicating KJNodes.

## Regional Prompt Builder

- Integrated KJ `Ideogram4PromptBuilderKJ` with the Comfy API DynamicCombo format.
- Added structured JSON regional prompting for `obj` and `text` boxes.
- The side-menu prompt is used as the full-canvas base scene, with added boxes layered as regional refinements.
- Fixed regional background generation so negative prompts are never used as scene background.

## Linear Viewer

- Added Ideogram regional guide canvas in Linear Viewer for txt2img and img2img.
- Added ADD object/text boxes, move, resize, delete, undo, redo and close-menu behavior.
- Added layer ordering controls so overlapping boxes can be sent backward or brought forward.
- Synchronized canvas dimensions and img2img reference preview with side-menu resolution.

## Runtime And Defaults

- Updated Ideogram defaults to CFG 1, Euler/Simple, 12 steps and conservative img2img denoise.
- Uses the current Comfy route with ModelSamplingAuraFlow, CFGOverride, DualModelGuider, BasicScheduler, ExtendIntermediateSigmas and SamplerCustomAdvanced.
- KJNodes can be updated automatically for existing users without requiring a downgrade.
- The route stays compatible with Sage/xFormers preference, using SDPA only as fallback runtime behavior.

## Validation

- Legacy `/ui` battery covered txt2img and img2img, with no boxes, obj+text boxes, obj-only and text-only.
- img2img smoke used `input/SokeTestIdeogram.png` at its native 912x512 resolution.
- Visual inspection confirmed coherent txt2img, img2img preservation, functional obj boxes and usable text boxes with known model-level text variability.
