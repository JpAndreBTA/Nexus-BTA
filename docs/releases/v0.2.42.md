# NexusBTA v0.2.42

## MiniMax H3 video-reference optimization

- Replaces full-file `LoadVideo` plus `GetVideoComponents` processing with the bounded `VHS_LoadVideo` route.
- Normalizes each MiniMax H3 reference video to the FPS, width and height selected in the Nexus UI.
- Stops decoding at the H3-aligned generation frame count before reference VAE and Qwen processing.
- Routes the matching bounded soundtrack directly into `MiniMaxH3ReferenceToVideo`.
- Preserves support for up to three reference videos together with image and standalone audio references.

## Dependencies and paths

- Treats Video Helper Suite as a required MiniMax H3 runtime node.
- Detects the node quickly when ComfyUI is stopped without recursively scanning custom-node repositories.
- Installs Video Helper Suite and its requirements only when absent.
- Respects the configured `custom_nodes_dir` in `run.bat`, LAN/tunnel startup, runtime refresh and `update.bat` flows.

## Validation

- Python `compileall` for the backend package.
- PowerShell parser validation for all modified launcher and dependency scripts.
- Generated-workflow assertions at 12 FPS and 24 FPS.
- Live ComfyUI object schema validation for `VHS_LoadVideo`.
- Live bounded reference decode using five frames without loading MiniMax H3.
- MiniMax H3 asset status reports `GenerationReady: True` after backend restart.
