# NexusBTA v0.2.46

## MiniMax H3

- Adds an isolated REF2VA Image Edit toggle for exactly one image reference.
- Uses the official `MiniMaxH3ReferenceToVideo` node, the H3-required five-frame latent, and `ImageFromBatch` to save the first edited frame as PNG.
- Defaults Image Edit to 8 sampling steps while keeping the UI value editable and synchronized with the backend scheduler.
- Keeps Image Edit separate from video references, audio references, custom workflow overrides and LTX latent video upscale.
- Adds temporary silent AAC normalization for reference videos without audio so VHS extraction succeeds after generation.

## LTX 2.5 and H3 Latent Upscale

- Adds native LTX 2.5 spatial and temporal latent-upscale asset discovery and UI controls.
- Adds the MiniMax H3 to LTX 2.5 latent bridge as an opt-in route; native H3 output remains unchanged when disabled.
- Keeps the LTX 2.3 bridge isolated and preserves user-selected model paths.

## Validation

- Python compilation passed for the modified backend modules.
- Frontend inline JavaScript syntax check passed.
- Offline H3 Image Edit workflow assertions passed for default and custom steps.
- Existing H3 video and generation contract smoke tests passed.
