# NexusBTA v0.2.44

## MiniMax H3

- Normalizes reference videos to the UI-selected FPS and resolution.
- Stops decoding at the H3-aligned frame count before reference VAE and Qwen processing.
- Keeps the official nine-image, three-video and three-audio reference limits.
- Detects and installs Video Helper Suite only when missing, using the configured custom-nodes path.

## Train LoRA

- Uses `anima_train_network.py` for the Anima Kohya preset.
- Separates dataset TOML from the actual Kohya training TOML passed to `--config_file`.
- Resolves optional Anima Qwen3/VAE paths from the configured model directory.
- Forces UTF-8 trainer output on Windows.

## Krea 2

- Adds a dedicated KREA 2 template without changing SD, Flux, Qwen, Anima, LTX, WAN, Ideogram 4 or MiniMax H3 routes.
- Uses ComfyUI's native `CLIPLoader(type=krea2)` and `TextEncodeQwenImageEditPlus` nodes.
- Supports text-to-image and up to three ordered local style/reference images, with optional Krea 2 style LoRA.
- Stores downloads under `models/diffusion_models/krea2`, `models/text_encoders/krea2`, `models/vae/krea2` and `models/loras/krea2`, while preserving standard Comfy category discovery and a `models/krea2` organization root.
- Detects the available RTX profile from `nvidia-smi`, recommends 768px shared/offload settings for RTX 3060-class cards and 1024px settings for RTX 5090-class cards, and applies that initial size in the UI.
- Writes an additive native Comfy model-path map for the configured custom `models_dir`, so the Krea 2 subfolders remain discoverable after restart without changing existing templates.
- Asks before downloading the base model and required files; no model or backend restart is triggered automatically.
- The official style-reference and Darkbrush LoRAs are detected and can be downloaded together; user LoRAs and the style adapter are chained without replacing each other.
- Krea 2 has no extra Python/custom-node requirement because the installed ComfyUI core already exposes the required nodes.

## Validation
