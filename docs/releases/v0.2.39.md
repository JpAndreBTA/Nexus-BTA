# NexusBTA v0.2.39

## Mobile UI

- Gallery fullscreen now displays only the selected image or video across the viewport.
- Previous/next controls remain available in fullscreen, with horizontal swipe navigation on mobile.
- The mobile device Back action exits fullscreen first, then closes the gallery or Civitai view in order.
- Side-menu panels can be reordered from the grip handle without blocking normal touch scrolling.
- Civitai requests can resolve the LAN backend and lazy search no longer repeats rejected cursors.

## LTX 2.3

- Input and timeline frames preserve their aspect ratio with edge padding instead of stretching.
- Qwen-to-LTX transitions restore the configured SageAttention runtime before generation.
- Tokenizer and attention changes restart only ComfyUI when required; the Nexus backend stays online.

## Workflow Synchronization

- Qwen uses its safe xFormers/PyTorch attention route and LTX returns to the configured video attention route.
- VAE and text encoder selections remain synchronized with the side menu and are never forcibly replaced.
- Compatibility warnings identify suspicious assets while preserving explicit user choices.

## Validation

- Qwen Image Edit and LTX 2.3 were generated sequentially through `/ui`.
- Runtime logs confirmed xFormers for Qwen and SageAttention for LTX.
- LTX completed without the invalid-tokenizer failure.
- Desktop and mobile gallery fullscreen, navigation, swipe and Back behavior were exercised visually.
