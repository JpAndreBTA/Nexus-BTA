# NexusBTA v0.2.43

## MiniMax H3

- Normalizes reference videos to the UI-selected FPS and resolution.
- Stops decoding at the H3-aligned frame count before reference VAE and Qwen processing.
- Routes the matching bounded soundtrack directly into `MiniMaxH3ReferenceToVideo`.
- Preserves up to nine ordered image references, three reference videos and three standalone audio references.
- Detects and installs Video Helper Suite only when missing, using the configured custom-nodes path.

## Train LoRA

- Uses the dedicated `anima_train_network.py` entry point for the Anima preset.
- Generates the dataset TOML and the real Kohya training TOML separately; Kohya receives the latter through `--config_file`.
- Resolves optional Anima Qwen3/VAE model paths from the configured models directory.
- Normalizes resolution and trainer values before writing TOML, avoiding malformed configuration files.
- Forces UTF-8 subprocess output on Windows so non-ASCII trainer status does not abort the job.

## Validation

- Backend Python compilation passed.
- Existing MiniMax H3 workflow and bounded video-reference checks remain covered.
- The running backend/ComfyUI process was not restarted while a user training job was active.
