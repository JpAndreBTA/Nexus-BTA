# NexusBTA v0.2.30

## Runtime Attention Settings Hotfix

- SageAttention, xFormers, FlashAttention and PyTorch SDPA toggles in Settings now save as independent runtime preferences.
- The PyTorch SDPA checkbox is now persisted through `enable_pytorch_attention`, so disabling it no longer silently resets after saving or re-rendering settings.
- Presets that prefer xFormers no longer force SageAttention off when the user intentionally chooses Sage + xFormers.

## Compatibility Sets

- Sage + SDPA: starts ComfyUI with Sage as the primary backend while disabling xFormers.
- Sage + xFormers: keeps xFormers available while using Sage as the primary optimized attention path.
- xFormers + SDPA: keeps ComfyUI on its default xFormers path with PyTorch attention still allowed.
- SDPA only: starts ComfyUI with `--use-pytorch-cross-attention`.
