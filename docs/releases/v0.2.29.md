# NexusBTA v0.2.29

## Blackwell xFormers Runtime Hotfix

- Added a real CUDA xFormers operator probe before Nexus marks xFormers as available.
- The probe runs a tiny `xformers.ops.memory_efficient_attention` call with the same BF16-friendly head shape that failed on RTX 5090 / Blackwell reports.
- Auto/Sage runtime paths now disable xFormers when the operator probe fails, allowing ComfyUI to fall back instead of crashing during Z-Image or Flux Klein generation.

## Runtime Diagnostics

- `/api/runtime/capabilities` now reports the actual xFormers CUDA operator failure instead of only checking whether `xformers` imports.
- This makes broken Torch/xFormers/Blackwell combinations visible as runtime incompatibility rather than model or VRAM failure.

## Validation

- `runtime/.venv/Scripts/python.exe -m py_compile backend/nexus_backend/comfy_client.py backend/nexus_backend/main.py`
- Local BF16 xFormers kernel probe passed with output shape `(1, 32, 30, 128)`.
- `git diff --check -- backend/nexus_backend/comfy_client.py backend/nexus_backend/main.py` passed with CRLF warnings only.
