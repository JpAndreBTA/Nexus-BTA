# NexusBTA v0.2.28

## Ideogram-4 Functional Hotfix

- Fixed Ideogram-4 regional generation so UI boxes are serialized through KJ `elements_data`, matching the native `Ideogram4PromptBuilderKJ` editor format.
- Stopped sending regional bbox JSON through `import_json`, which could make the model render guide labels, borders, selection marks or malformed annotations into the final image.
- Kept text and object region coordinates synchronized across legacy `/ui`, txt2img, img2img and the backend workflow.
- Added `preserve image` as the effective img2img side prompt when a reference image exists and the positive prompt is empty.

## Text, Brands And Clean Output

- Added an Ideogram-4 clean-output directive for txt2img and img2img to avoid unintended visible writing, borders, glyphs, stamps, signatures and watermarks.
- Text regions now allow only their exact requested words instead of encouraging extra text outside the selected area.
- Brand, logo, label, sign and watermark details are allowed only when the global prompt or a regional edit explicitly requests them.
- Negative prompts that mention watermark/logo do not unlock brand rendering by themselves.

## Legacy UI

- Region overlays now render only on the Ideogram guide/reference canvas.
- Generated outputs stay clean in the Linear Viewer instead of being covered by editor boxes.
