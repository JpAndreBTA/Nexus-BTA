# NexusBTA v0.2.27

## Offline UI Hotfix

- Removed startup dependence on online Tailwind, Google Fonts, Font Awesome, Three.js ESM CDN, Unsplash and MediaPipe CDN assets.
- Added local browser assets under `assets/vendor/` so `/ui` can load after first setup without internet.
- Ko-fi and Google Translate now stay optional online actions instead of blocking local startup.
- MediaPipe pose capture loads its local WASM and pose landmarker model first.

## Backend And Comfy Sync

- Offline browser mode still talks to the local Nexus backend and embedded ComfyUI endpoints.
- Missing dependency/model downloads now show a clear reconnect/manual-install message when the browser is offline.
- Civitai search, resolve and download flows now fail with an offline notice instead of trying network calls.

## xFormers Runtime

- Replaced the direct Windows xFormers wheel URL with normal `xformers==0.0.35` pip resolution.
- Attention runtime setup now import-checks xFormers, Triton and SageAttention before attempting downloads.
- PowerShell wrappers keep native pip retry warnings from surfacing as red `NativeCommandError` output.

## Ideogram-4

- Includes the functional Ideogram-4 frontend route, asset status/download contract and regional prompt state.
- Keeps the Ideogram-4 compatibility work from `v0.2.26` while adding offline-safe dependency behavior.

## Validation

- Legacy `/ui` smoke test passed with browser offline simulation and all non-localhost requests blocked.
- Local Nexus and embedded ComfyUI health/object-info checks passed while offline.
- Local Tailwind, fonts, Font Awesome, Three.js addons, MediaPipe WASM and pose model assets loaded successfully.
- xFormers, Triton and SageAttention import probes passed in the bundled runtime.
